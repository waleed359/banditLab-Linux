## OverTheWire Notes

A personal log of my progress through the OverTheWire wargames. The purpose of this repository is to document what each level taught me, the approaches I attempted, and the commands that ultimately worked.

Passwords are intentionally omitted so as not to spoil the challenges for others.

## Progress

- **Bandit:** in progress (level 6)
- **Natas:** not yet started

## Repository Structure

Each level is documented in its own Markdown file within the corresponding wargame directory (e.g. `bandit/level00-01.md`). Every file follows the same format:

- The objective of the level
- Concepts and commands learned
- Approaches attempted, including those that did not succeed
- The final solution
- Reflections and notes for future reference

## Purpose

This repository serves both as a study aid and as a record of my learning process in Linux, networking, and security fundamentals.
